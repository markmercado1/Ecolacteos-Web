# EcoLácteos Web — instrucciones de trabajo

Este repositorio contiene el panel web Angular de EcoLácteos. La fuente de continuidad es el repositorio, no el historial del chat.

Antes de actuar, lee en orden:
1. `docs/REGLAS.md`.
2. `docs/ESTADO.md`.
3. `docs/DECISIONES.md`.
4. La fase activa en `docs/FASES.md`.
5. Los contratos y guías necesarios para esa fase.

Cumple las reglas compartidas y actualiza ESTADO al cerrar una sesión. No declares trabajo terminado sin evidencia. Registra hechos del proyecto, archivos, decisiones y pruebas. Preserva todos los cambios previos.

Si solo existe esta documentación, el próximo trabajo es Fase 1. No implementes todos los módulos a la vez. Una instrucción explícita del usuario puede ampliar el alcance.
